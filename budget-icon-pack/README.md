# Transparent Studio Budget icon files

## Where to put these

For a Vite/React app:

1. Put the contents of the `public` folder into your project's `public` folder.
2. Replace your existing root `index.html` with the included `index.html`.
3. Redeploy the app.
4. Remove the old installed app from your Dock or Applications folder, then install/add it again so macOS/browser refreshes the cached icon.

## Important note

The PNG, SVG, ICO and ICNS files in this pack preserve alpha transparency. Some browser or macOS install methods may still place the icon inside a rounded-square tile. That square is added by the browser/OS, not by these image files.

For a manually assigned Mac app/folder icon, use `StudioBudget-transparent.icns`.
